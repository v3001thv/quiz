# Тест «Инновационная инфраструктура Республики Беларусь»

Сайт-тест: 20 вопросов, 7 минут, оценка 0–10, база результатов и панель администратора.

## Что внутри

```
public/            — сам сайт (страница, стили, эффекты)
netlify/functions/ — серверная часть: старт теста, проверка ответов, админ-панель
netlify/lib/       — вопросы с правильными ответами (хранятся только на сервере) и общие функции
netlify.toml       — настройки для Netlify
package.json       — зависимость @netlify/blobs (хранилище результатов)
```

Результаты хранятся во встроенном хранилище **Netlify Blobs** (хранилище `quiz-attempts`).
Отдельную базу данных подключать не нужно.

## Как выложить на Netlify

⚠️ Простое перетаскивание папки (Netlify Drop) может не подключить серверные функции —
тогда тест не запустится. Используйте один из двух способов ниже.

### Способ 1 — через GitHub (без командной строки)

1. Зарегистрируйтесь на github.com, нажмите **New repository**, назовите, например, `quiz`.
2. На странице репозитория: **Add file → Upload files** и перетащите ВСЁ содержимое этой папки
   (`public`, `netlify`, `netlify.toml`, `package.json`, `README.md`). Нажмите **Commit changes**.
3. На app.netlify.com: **Add new project → Import an existing project → GitHub** → выберите репозиторий.
4. Настройки сборки трогать не нужно — они берутся из `netlify.toml`. Нажмите **Deploy**.
5. Через минуту-две появится ссылка вида `https://имя-сайта.netlify.app` — её и отправляйте одногруппникам.

### Способ 2 — через Netlify CLI

```bash
npm install -g netlify-cli
netlify login
cd папка-с-сайтом
npm install
netlify deploy --prod
```

При первом запуске CLI предложит создать новый сайт — согласитесь.

## Панель администратора

* Кнопка с замочком в левом нижнем углу → пароль → панель с результатами.
* Видно: имя, правильные ответы, процент, оценку 0–10, сколько вопросов успел ответить, время, статус
  («завершил», «время вышло», «проходит сейчас», «не завершил»).
* **Скачать CSV** — файл с результатами для Excel.
* **Очистить историю** — удаляет все записи; нужно ввести слово `ОЧИСТИТЬ` для подтверждения.
  Можно удалить и одну запись (крестик в строке).

### Сменить пароль

В коде хранится не сам пароль, а его хэш. Чтобы задать новый пароль:
Netlify → ваш сайт → **Project configuration → Environment variables → Add a variable**
`ADMIN_PASSWORD` = новый пароль → затем **Deploys → Trigger deploy**.

## Как это работает

* Таймер идёт на сервере: время начала записывается при нажатии «Начать тест».
  Перезагрузка страницы не сбрасывает время — тест продолжится с того же места.
* Правильные ответы никогда не отправляются в браузер, проверка — на сервере.
* Варианты ответов перемешиваются для каждого участника.
* Оценка = доля правильных ответов × 10, округление до целого.
* Если время вышло — ответы отправляются автоматически, на экране видно, сколько вопросов человек успел ответить.
* Эффекты: 9–10 — большой фейерверк и конфетти, 8 — фейерверк, 6–7 — конфетти,
  4–5 — искорки, 0–3 — дождик. За 2,5 минуты до конца или при отставании от темпа экран
  постепенно краснеет, в последние 30 секунд — «пульсирует».

## Изменить вопросы

Файл `netlify/lib/questions.mjs`: текст вопроса, варианты `a`–`d` и буква правильного ответа `correct`.
Время теста — константа `TIME_LIMIT_SEC` там же.
